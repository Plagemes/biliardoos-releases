Questions and ideas
Is it really free?

The Base version of BiliardoOS is free to download and use, with no software subscription. It is not open source: all rights are reserved. Full terms are in the project licence.

What championships is it built for?

For amateur Italian billiards and boccette championships between bars, clubs and associations: heats of 4 or 8 players, singles or pairs, followed by a final phase. The draw respects configured rules such as venues, availability and seeded players.

Can I use it without Internet?

Yes, for day-to-day work: draws, printed call-ups, roll call, results and standings. Internet is needed to download the app and AI model, receive updates and use online features such as WhatsApp and email sending.

How do AI and my data work?

The championship database and AI assistant live on your PC. Local AI uses Ollama and requires an initial model download selected for your hardware. Communications and sync options, when enabled, use their respective external services.

Does it work on a phone or Mac?

The desktop app is available for 64-bit Windows 10 and 11. A phone can be used for dedicated result-entry features through the local connection configured from the PC. It is not a native Android, iPhone or macOS app.

Why does Windows show a warning?

The current installer is not digitally signed, so Windows may display a SmartScreen warning. Download only from the project repository releases and scan the file with Windows Security before proceeding. A warning alone does not prove a file is safe or unsafe: if you are unsure of its source, do not run it.

More details are available in the installation instructions.

Are updates and support included?

The app checks for new versions at startup; you can also check from Settings → Updates. Updates are preceded by a backup and are not installed during an active match night. For questions, use Discussions; to report a problem, open a GitHub issue. The software is provided without warranties, according to the licence.
